# 11 — MVP Content Plan

# Objetivo

Evitar el error de lanzar miles de URLs sin estrategia.

---

# Games — lanzamiento

Meta inicial:

```text
600 juegos
```

Distribución sugerida:

```text
Casual        100
Puzzle         80
Action         70
Racing         70
Sports         60
Arcade         60
Adventure      50
Multiplayer    40
Strategy       40
Other          30
```

No fijar estas cantidades si el proveedor ofrece contenido de baja calidad.

Priorizar:

- thumbnail atractivo;
- mobile;
- carga rápida;
- controles claros;
- inglés/español cuando exista;
- popularidad/relevancia.

Categorías:

- browsers;
- media;
- compression;

- communication.

No alojar binarios en MVP.

Cada registro debe enlazar a fuente oficial.

---

# Guides

Primeras guías deben apoyar páginas que ya existan.

Ejemplo:

```text
/tool/image-compressor
+
/guide/how-to-compress-an-image
```

o:

```text
/app/vlc-media-player
+
/guide/how-to-install-vlc
+
/guide/best-vlc-alternatives
```
