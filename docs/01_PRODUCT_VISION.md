# 01 — Product Vision

# 1. Qué es Gametroz

Gametroz es una plataforma web gratuita de entretenimiento y utilidad.

Debe permitir que un visitante pueda:

- Jugar inmediatamente.
- Encontrar nuevas experiencias.
- Utilizar herramientas online.
- Descubrir software útil.
- Consultar guías.
- Pasar fácilmente de un contenido a otro.

La marca no debe sentirse como "una web llena de publicidad".

Debe sentirse como un producto real.

---

# 2. Propuesta de valor

## Games

> Juega gratis directamente desde el navegador.

## Tools

> Resuelve tareas rápidas sin instalar software.

## Apps

> Descubre software útil y descarga desde fuentes confiables.

## Guides

> Aprende a utilizar juegos, herramientas y aplicaciones.

---

# 3. Público objetivo

Gametroz apunta inicialmente a:

- Usuarios entre 13 y 45 años.
- Mobile y desktop.
- Personas que buscan entretenimiento casual.
- Usuarios que necesitan resolver tareas rápidas.
- Usuarios buscando software gratuito o freemium.
- Público hispanohablante inicialmente.
- Inglés y portugués en fases posteriores.

---

# 4. Objetivos de negocio

## Métrica primaria

**Páginas vistas monetizables mensuales.**

El producto debe favorecer:

- sesiones con múltiples páginas;
- navegación relacionada;
- retorno de usuarios;
- tiempo de permanencia;
- descubrimiento interno.

## Métricas secundarias

- Usuarios mensuales.
- Sesiones mensuales.
- Pageviews por sesión.
- CTR en elementos relacionados.
- Tiempo en página.
- Retorno de usuarios.
- Páginas indexadas.
- Tráfico orgánico.
- RPM/eCPM publicitario.
- Ingreso mensual por publicidad.

---

---

# 6. Prioridades del MVP

Orden de prioridad:

1. Games.
2. Search / discovery.
3. SEO.
4. Related content.
5. Tools.
6. Apps / Software.
7. Guides.
8. Monetización.

---

# 7. Qué NO debe ser Gametroz

No debe ser:

- un clon visual de Poki, CrazyGames, Softonic o Uptodown;
- un portal de descargas dudosas;
- una colección automática de miles de páginas vacías;
- una web saturada de anuncios;
- un repositorio de juegos copiados sin autorización;
- una granja de contenido generado por IA sin revisión;
- un sitio que fuerce descargas;
- una web que confunda botones publicitarios con botones reales.

---

# 8. Identidad de marca

Nombre:

**GAMETROZ**

Tagline:

**Play · Tools · Apps**

Personalidad:

- tecnológica;
- divertida;
- limpia;
- veloz;
- moderna;
- confiable;
- internacional.

Evitar una estética excesivamente infantil.

Gametroz debe poder funcionar igual de bien para un juego casual, un convertidor de imágenes o una ficha de VLC.
